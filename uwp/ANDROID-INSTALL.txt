Zelda Fusion — Android-to-Xbox install
========================================================

These instructions apply to a future signed Fusion development package. This source checkpoint
only establishes a separate identity; it is not a completed OoT/MM fusion game. The inherited
runtime currently accepts OoT archives; MM and raw-ROM import support are still pending.

The package is ROM-free. You do not need a PC, Visual Studio, a command line,
GitHub signing setup, or a certificate tool to install a provided signed package.

1. On Android, download and unzip the GitHub Actions artifact named
   ZELDA-FUSION-XBOX.
2. Open Xbox Device Portal in your phone browser and go to Apps.
3. Choose the included .msix (or .appx) as the app package, the included
   public .cer as the certificate, and any .appx/.msix files under
   Dependencies as dependencies.
4. Install it alongside your existing apps. Its identity is separate from every previous build.
5. In Device Portal, open File Explorer, then LocalAppData, then
   the package starting with WesKestis.ZeldaFusion.UWP, then LocalState, then the soh folder.
   This is Fusion's own storage. Keep previous builds' files in their own package folders.
   Launch the app once first if the soh folder is not present yet.
6. Upload your private files into LocalState\soh:
      oot.o2r       Normal Quest (at least one quest archive is required)
      oot-mq.o2r    Master Quest (optional)
      oot3d.3ds     decrypted OoT3D source used by the graphics toggle
7. Launch the app again from Device Portal or My games & apps.

If install fails, keep the Device Portal error text. If the app closes during
launch, refresh that same LocalState\soh folder and open uwp-boot.log. It is
rewritten on every launch, so its final stage identifies the failed startup
boundary even when Xbox Crash Data produces no dump.

If launch succeeds, report whether Original and OoT3D modes render, whether
L3+R3 toggles the V3 cursor, and whether View/F1 opens the full settings menu.
