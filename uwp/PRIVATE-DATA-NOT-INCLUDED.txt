PRIVATE GAME DATA IS NOT INCLUDED
=================================

The package contains game-engine code and ROM-free port assets. Upload your own
game archives through Xbox Device Portal after installing the separate Fusion app:

  LocalState\soh\oot.o2r
  LocalState\soh\oot-mq.o2r
  LocalState\2ship\mm.o2r

The diagnostic requires the archive for the selected game. No 3DS image is needed.
Never upload private ROMs, game archives, saves or signing keys to GitHub Actions
or commit them to this repository. Raw-ROM import is not implemented in this test.
